LVM(logical volume manager)
- flexible way to manage storage on linux
- PV(physical volume):actual disk/partition
- VG(volume group):pool of storage made from PV, group = pile of space
- LV(logical volume):virtual partitions you actually use, logical = pretend partition

UFW(uncomplicated firewall)
- simple tool to manage linux firewall
- a firewall is a security tool that controls what traffic enteres or leaves your machine
- UFW = easy firewall, linux's built-in firewall is powerful but complicated
UFW commands:
sudo ufw enable: turn firewall ON, UFW starts filtering incoming and outgoing network traffic based on the rules
sudo ufw status: check rules, verbose mode(more details): sudo ufw status verbose
sudo ufw allow 22: allow SSH on port 22, otherwise the connection will be blocked by firewall
sudo ufw deny 80: blocks incoming connections on port 80(usually for HTTP web traffic), for better security by reducing attack surfaces if not running a web server
sudo ufw default deny incoming: deny all incoming traffic unless i explicitly allow it, protects the system by blocking all unwanted or unknown connections by default
sudo ufw default allow outgoing: sets the default policy to allow all outgoing traffic, send data out or access external services, safe since outgoing traffic doesn’t expose the server to external attacks

configure password complexity rules
- nano /etc/pam.d/common-password: edit PAM (pluggable authentication modules)
- after retry=3, add "minlen=10 ucredit=-1 dcredit=-1 lcredit=-1 maxrepeat=3 reject_username difok=7 enforce_for_root"
minlen=10 : must contain minimum 10 characters
ucredit=-1 : must contain at least one capital letter
(we must write it with a - sign, as this is how it knows that it refers to minimum characters; if we put a + sign it will refer to maximum characters)
dcredit=-1 : must contain at least one digit
lcredit=-1 : must contain at least one lowercase letter
maxrepeat=3 : cannot have the same character repeated three consecutive times
reject_username : cannot contain the username within itself
difok=7 : must contain at least seven different characters from the last password used
enforce_for_root : implement this password policy for root

script commands explanation:
- uname -a: prints all available system info in one line
- grep "physical id" /proc/cpuinfo | wc -l: grep = search for text patterns in files or output, wc -l = count lines of output
- free --mega | awk '$1 == "Mem:" {print $3}: free = shows memory usage (RAM and swap), --mega = displays the memory in megabytes, awk = text-processing tool used to extract and manipulate columns of data, $1 == "Mem:" {print $3} = look for lines where first column($1) is Mem and print the third column($3) from that line OR {printf("(%.2f%%)\n", $3/$2*100)}: .2 = two decimal places, f = floats for printf
- df -m | grep "/dev/" | grep -v "/boot" | awk '{memory_use += $3} END {print memory_use}': df = disk filesystem usage, -m = size in megabytes, -v = invert match(removes any filesystem at /boot), awk = processes each remaining line and automatically splits lines into fields (default separator = whitespace) "awk '<pattern> {<action>}' file", += = adds up all 3 values
- vmstat 1 4 | tail -1 | awk '{print $15}': vmstat = virtual memory statistics, 1 = interval in seconds, 4 = number of reports, tail -1 = last line of output
- who -b | awk '$1 == "system" {print $3 " " $4}': who = shows info about logged in users and system status, -b = last system boot
- if [ $(lsblk | grep "lvm" | wc -l) -gt 0 ]; then echo yes; else echo no; fi: if [ ... -gt 0 ]; then ... = if ... is greater than 0 , fi = shell keyword that ends an if block
- ss -ta | grep ESTAB | wc -l: ss = socket statistics (modern replacement for netstat), -t TCP sockets only, -a = all TCP sockets (listening + non-listening), grep ESTAB = filters only sockets in the ESTABLISHED state
- users | wc -w: users = show the names of users there are
- ip link | grep "link/ether" | awk '{print $2}': ip link = show info about network interfaces
- journalctl _COMM=sudo | grep COMMAND | wc -l: journalctl = tool to read systemd journal logs, _COMM=sudo = filters logs only from the sudo command

Sockets
-  an endpoint for communication between two programs, usually over a network, 
Types of sockets
1. TCP sockets
Reliable, ordered, connection-based
Used by: HTTP, HTTPS, SSH, FTP, SMTP
2. UDP sockets
Faster, connectionless, no delivery guarantee
Used by: DNS, streaming, gaming
3. Unix domain sockets
Local-only (no network)
Faster than TCP for same-machine communication
What “socket state” means
1. LISTEN → waiting for connections
2. ESTABLISHED → active connection
3. TIME-WAIT, CLOSE-WAIT, etc. → closing

wordpress logic:
- a user visits your website in a browser (http://yourserver.com).
- Lighttpd receives the HTTP request.
- If the request is for a WordPress page:
- Lighttpd passes the request to PHP (via FastCGI or PHP-FPM).
- PHP executes WordPress scripts.
- When WordPress needs content (like a post or user info), it queries MariaDB.
- MariaDB responds with the requested data.
- WordPress combines the data with PHP templates and sends the HTML output back through Lighttpd to the browser.
- Essentially: Lighttpd = delivery, PHP = logic, MariaDB = storage, WordPress = orchestrator.
